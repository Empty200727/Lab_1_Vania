# ЛР 1 — знакомство с Python

Предмет: **Теория алгоритмов** (3 курс).

Здесь лежат решения первой лабораторной: 11 маленьких задач на базовые типы
Python, главный модуль, который запускает их все подряд, и тесты.

## Что где лежит

- `python_lab_01/` — задания `00_distance.py` … `10_store.py`;
- `main.py` — запускает все задания по очереди;
- `tests/` — тесты pytest (`test_basics.py`, `test_collections.py`, `test_main.py`);
- `pytest.ini` — настройки pytest;
- `requirements.txt` — список пакетов;
- `REPORT.md` — отчёт.

## Задания

1. **00_distance** — словарь словарей расстояний между Москвой, Лондоном и Парижем.
2. **01_circle** — площадь круга радиуса 42 и проверка двух точек.
3. **02_operations** — `1 + 2 * (3 + 4 + 5) = 25`.
4. **03_favorite_movies** — названия фильмов из строки через срезы.
5. **04_my_family** — рост папы и всей семьи.
6. **05_zoo** — медведь, птицы и слон в списке зоопарка.
7. **06_songs_list** — время звучания песен Depeche Mode.
8. **07_secret** — секретная фраза из пяти строк.
9. **08_garden** — цветы сада и луга как множества.
10. **09_shopping** — где дешевле всего купить сладости.
11. **10_store** — сколько товаров на складе и на какую сумму.

## Как запустить

```bash
python -m venv .venv
.venv\Scripts\activate          # на Linux: source .venv/bin/activate
pip install -r requirements.txt

python main.py                  # все задания
python python_lab_01/05_zoo.py  # одно задание
```

## Тесты

```bash
pytest -v
```

Все **18** тестов проходят.
